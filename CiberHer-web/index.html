Qué trae el .zip

Las 23 pantallas en HTML enlazadas entre sí, el mapa de flujo 00-mapa-de-flujo.html y un index.html para abrirlo en cualquier navegador o subirlo a Netlify o GitHub Pages.

Llevarlo a Figma ordenado

  1. Instale el plugin html.to.design.
  2. Suba 00-mapa-de-flujo.html: llega como un solo tablero con las filas y flechas de este mapa.
  3. Para el Play, enlace cada botón con su pantalla en la pestaña Prototype, siguiendo las flechas.

Datos de ejemplo

Los nombres y correos son de muestra. Lo que se escribe en los campos no se guarda; cada estado está prediseñado como pantalla.
